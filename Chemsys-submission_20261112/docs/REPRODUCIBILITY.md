# Reproducibility

## Offline verification

Run `python -B research.py verify` with Python 3.10 or later. It uses the standard library and requires no credential. It checks all dataset hashes/ID orders, finite responses, source provenance, documented path changes, key paper values and the complete file manifest. Archive subsets are identified as subsets; they are not assigned the full original archive's hash.

## Rebuilding saved evidence

`python -B research.py rebuild-results all` dispatches five offline jobs. Each calls the unchanged native analysis code, or the specific retained analysis functions for Test F and the condensed knowledge audit. No model, GP fit or experimental decision is executed. Run individual jobs with `development`, `heldout`, `screen`, `first_points` or `knowledge`.

`python tools/export_metrics.py` indexes the included complete states. It does not combine cohorts or compute a new claim of significance. `results/trajectory_metrics_notes.json` identifies incomplete states and the exact denominator.

The rebuild runs in a disposable copy and compares its tables with the frozen results. The verification receipt lists every rebuilt file, including numeric comparisons with a tolerance of 1e-9. The outputs go to a new directory under `output/`. The archived inputs and tables remain suitable for `research.py verify` after a rebuild.

`python -B tools/check_submission_evidence.py` verifies the upstream screen CSVs, S8, Test G and the fixed-trajectory deoxyfluorination check. Add `--snar` to reproduce the noise-free Summit sensitivity calculation. `python -B tools/build_figures.py` regenerates Figures 2–5 into a separate directory and validates the model-specific data for Figure 3. For these optional numerical and plotting checks, install `environment/requirements-submission-checks.txt`.

## Numerical methods

Use CPython 3.10 with `environment/requirements.txt`. The recorded numerical environment used CPU PyTorch 2.5.1, BoTorch 0.14.0, GPyTorch 1.14, NumPy 1.24.4, SciPy 1.12.0 and pandas 1.5.3. Install `environment/requirements-llm.txt` when constructing new molecular background cards; it adds the original RDKit version. Verification and saved-evidence rebuilds do not require it.

`python tools/run_bo.py --task c1 --seed 0` explicitly starts a new 0+20 campaign. Selection uses the original `SeededGP`/`ColdGP` classes, exact acquisition ties and feature-keyed tie streams. The first no-data choice uses a seeded neutral prior order; qLogEI begins after an observation exists. Native operators warm once before the loop. Numerical fit caches and new states are stored under `output/new_bo/`, away from dataset inputs and frozen evidence.

The new BO entry point was checked for argument parsing and all 13 public pool loads. A new optimization trajectory was not run as part of this packaging task. Cross-machine numerical replay is distinct from reproducing an archived LLM response or demonstrating a scientific improvement.

## LLM-guided experiments

Primary-model request code is in `hypothesis_scope_v2/transport.py`. Set `CHEM_OPENAI_CONFIG` to an external configuration file accepted by `chem.benchmarks.knowledge_openai_client.load_config`. Model aliases and the original reasoning settings remain in the method package. The DeepSeek transport reads the external path in `CHEM_DEEPSEEK_CONFIG` and expects `BASE_URL` and `DEEPSEEK_API_KEY` entries. Credentials and private reasoning are not copied into this project.

The original study runners retain historical preparation, frozen-protocol and source-hash dependencies. `python tools/prepare_inputs.py` can materialize the original eight public input paths from `data/` without a query; the five held-out/screen inputs already exist in the selected evidence. Read the runners' preparation functions before starting a new cohort. This project supplies the scientific functions and selected evidence; it does not pretend that a missing historical registration or same-machine reference run can be regenerated by silently substituting a new run.

## Paper

The four TeX sources and PDFs are in `paper/hypothesis_scope_jcim/`. From the root, run `python -B tools/build_paper.py --english-only` for the English pair or `python -B tools/build_paper.py` for all four documents. The tested TeX engine was Tectonic 0.17.0. If Tectonic is not on PATH, pass `--tectonic` with the executable location. Use `--only-cached` with an existing TeX bundle cache.

The builder compiles the English SI first and retains `si.aux`, which both manuscripts use for SI references. The Chinese sources use Times New Roman, Arial, Courier New, SimSun, SimHei and KaiTi. Use installed fonts or pass `--fonts-dir` with the locally licensed font files named in `tools/build_paper.py`. Figure geometry can vary with the renderer and fonts. The archive contains the authoritative figure assets and the PDFs built from them.
