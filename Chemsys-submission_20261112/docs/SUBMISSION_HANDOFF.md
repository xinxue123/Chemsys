# Submission handoff

Use this checkout with the [r3 evidence Release](https://github.com/xinxue123/Chemsys/releases/tag/submission-20261112-r3). RELEASE_DATA.json pins the archive name, byte length and SHA-256. Run the commands in [the project README](../README.md) from the version directory. The manuscript and Supporting Information in both languages are maintained in the local r3 submission bundle.

The repository retains the 13 original pool and oracle pairs. It also includes the CSV export of the 11 rows displayed in manuscript Table 6, the two model blocks of Table 4, the plotting tables, and the S8 and Test G data and checks. [Source coverage](../provenance/COVERAGE.md) records the boundaries of historical verification.
