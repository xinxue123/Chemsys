# Dataset descriptions

[dataset_registry.csv](dataset_registry.csv) records the eight primary pools, candidate counts, task units and original pool/oracle hashes. Perera uses UV chromatographic product area percent; Doyle uses reported reaction yield percent; SnAr uses space-time yield; HPLC uses source peak area.

Complete input/oracle tables and31,522 primary candidate rows remain in the local research bundle. The additional Direct Arylation transfer pool is also retained locally. See [local evidence requirements](../LOCAL_DATA_REQUIREMENTS.md). No oracle arrays or full candidate-level outcome files are added by this synchronization.
