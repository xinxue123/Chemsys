Case 1 pilot: unrestricted LLM first point and confidence-triggered refresh

Final user scope: LLM chooses only the first point, then seven qLogEI rounds.
There is no low/middle/high yield conditioning. Later LLM calls occur only
when prospective KF feedback degrades confidence. The user permits a refreshed
suggestion to change that round's point after qLogEI acquisition-budget review.
There is no ongoing LLM screening and no rollout.

Run ten independent replicate labels 0..9 with a common fixed input pool and
the existing shared Mixed GP/qLogEI recipe. Every trajectory has eight paid
observations. Three registered arms separate first-point and refresh effects:
1. bo: a uniform random initial point from the entire feature-sorted pool,
   followed by seven full-pool native qLogEI maxima.
2. event: one zero-observation LLM proposal and local knowledge forecasts,
   then full-pool native qLogEI except a reviewed confidence-event proposal.
3. llm_start_bo: copy the exact first point from the corresponding event arm,
   then seven full-pool native qLogEI maxima; no extra LLM calls. This arm
   isolates the effect of later confidence events from the initial-point effect.
Its initial query is charged as part of its own identical eight-query budget.
Run all trajectories to completion, including those reaching good yield early.

LLM: previously authorized fresh isolated gpt-6.1-terra medium responders.
Initial prompts have no observations, GP predictions, candidate yields,
yield-group information or benchmark target. They show the safe reaction
domain, nominal/opaque catalyst labels, and input-only coverage examples.
Any physical point in the full domain can be proposed. Project it onto the
nearest actual unqueried fixed-pool point with the same catalyst and cited
physical scopes, minimizing normalized continuous Euclidean distance. Exact
distance ties use the existing feature-based priorities. Reject a projection
farther than .35; abstention or invalid executable coverage falls back to
the predeclared unrestricted random initial rule. No new candidate is generated.

Each LLM reply contains an optional proposal and up to four local hypotheses
with favour/avoid scope and uncertain Normal yield forecasts. Reuse the frozen
per-note KF and lifecycle from llm_screen_qlogei. The initial experiment has
no incumbent, so no relative-improvement Brier update is defined for it. From
query2, commit every applicable claim's p_LLM and current p_GP before observing
the selected experiment. Score only actual selected feedback. Relative Brier
gain updates KF reliability. Confidence and recommendation permission remain
separate; an accurate failure cannot restore a paused favour recommendation.
Same-direction/same-scope edits retain evidence and permission after renaming
or numerical-forecast edits. Archived adverse observations remain in the prompt.

Normal query: choose the maximum native qLogEI over every unqueried candidate.
Knowledge does not filter or rerank it. If scored knowledge becomes paused due
to reliability<.2, two negative relative-skill updates, or repeated deployed
nonimprovement, call LLM at the next eligible query, at most two refreshes.
The refreshed proposal is projected onto the full unqueried pool as above.
Its favour basis must be active/provisional with reliability>=.2. It is executed
only when qLogEI(proposal)>=max(qLogEI)-log(2). Otherwise execute the unchanged
global qLogEI maximum. Thus any event deviation retains at least half the
current maximum exp(qLogEI), and the following normal round returns to full-
pool qLogEI. Refreshed knowledge is not continuously deployed between calls.

Keep original GP inputs, output units, nugget, priors, fitting after four
observations, MC512 seeds and feature-based exact ties. Never inject knowledge
as training data or modify GP mean/variance. All decision, projection, forecast,
LLM and state-hash records must precede oracle access. Preserve full GP scores.
Use persistent single-thread CPU workers and warm once, with zero in-loop JIT.
Atomic state writes retry brief Windows file-sharing collisions without changing
any experiment choice or refitting a model.

Evaluate all thirty trajectories, report first-point yield, the frozen good-yield
endpoint with censoring, final best and SearchAUC8. Compare event versus random
BO and, separately, event versus the exact-LLM-start BO control. This is a small
single-task pilot, not a stability claim. Record KF updates, pauses, refreshes,
proposal acceptances/rejections and actual deviations from current-prefix qLogEI.
Initial point improvements must not be attributed to KF or refresh. The stopped
low/middle continuous-screening study is retained but excluded from this result.
