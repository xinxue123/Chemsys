V14 prospective reason-card protocol, registered before new responses/outcomes

Implementation responds to the two frozen failure diagnoses, not a claim that
changing thresholds guarantees superiority. Targeted first validation contains
exactly six runs: Perera seed2, HPLC seed0, Case1 seed2, Doyle seed3, SnAr seed0,
HPLC seed2. These are two known failures plus four known gains, intentionally
selected diagnostic controls. No unbiased benchmark/stability inference.

All runs start with ZERO observations,20 paid queries. Reuse frozen candidate
pools, categorical/continuous GP implementations, singleton convention, native
MC512 qLogEI and numerical seed0. Only the first data-free menu stream uses the
registered starting seed; post-first exact ties and physical display use seed0.
First menus match the old methods. No change to GP/candidate truth or free data.
Old V13, Reasoning BO and pure BO controls are read-only and not rerun.

Each fresh gpt-6.1-terra medium child sees only public domain inputs, own measured
history, old Insights and this method's committed memory. No current numerical
GP output or rank, no oracle access, no other-arm history, no response reuse.
An original official confidence extractor supplies a PROPOSAL. V14 backend may
instead execute its own GP reference. This is an explicitly changed main method,
not an unmodified implementation of official Reasoning BO.

Every proposal includes a decision_card: concise joint claim, one/two physical
focus axes, improve/learn/review purpose, five independent probabilities of
strict improvement over CURRENT incumbent. All probabilities are null atq1.
The selected EXECUTED point's forecast is calibrated after the outcome, even
when no regional note applies or the backend rejects the proposal. Unexecuted
forecasts stay unlabelled; never feed them synthetic outcomes. Log both IDs.
The original scalar Brier-relative KF is unchanged. Its decision-channel trust
is shrunk toward0.4 with four prior pseudo-observations; this number is calibration,
not chemical causality or positive recommendation permission.

Gate fromq2: require both a positive LLM preference over GP reference and a
positive preference increment relative to the GP probability contrast. Max
allowed logEI loss is log(4)*shrunk_reliability*(1 for valid mature local support,
otherwise0.5). No GP mean/covariance is modified. At most two information-first
overrides lacking preference discrimination, only within first five queries or
an actual stagnation event. No untracked free positive recommendation bypass.
Correct failure forecasts alone do not grant/recover a local recommendation.

Regional note credit: actual focus changes are required, with unchanged
nonfocus categories and max0.25 normalized continuous background drift. Continuous
focus change must reach0.1. These approximate continuous contrasts remain local
predictive evidence, not isolated causal effects. Noneligible tests are explicitly
committed as calibration-only; keep their actual improvement in the search metric.
Do not attribute a boron/base/ligand improvement to an unchanged electrophile.

Physical local risk compares at most one categorical mismatch and max0.25 per
continuous coordinate. For an actual LLM override, create a scoped adverse fact
on a >=one observed-SD shortfall, an accurate failure forecast, or two local
unsuccessful overrides. SD floor is0.01 objective scale; singleton uses the
objective scale. Renaming a claim does not erase physical facts. GP itself is
not banned from querying any point. Scoped note suppression facts are also checked.
Positive override in such a neighborhood requires an explicit review proposal
and actual stagnation/material focus change. Note+card reviews share exactly
two paid-query allowances; consume only on deployment. One continuing plateau
has one identity. Two actual improving review tests release a local fact; failure
never releases it. Two failed review tests mark it withdrawn. Facts remain.

Editor: at least two observed experiments before first call; maximum four calls,
minimum gap3, reserve last call untilq12 unless fresh serious local adverse
evidence demands it. Trigger by true stagnation, consecutive negative predictive
skill, new adverse evidence or nonempty live notes with zero menu coverage.
A new incumbent alone does not force a call. Empty/retain calls still count.
Added/revised notes must cover at least two UNQUERIED public inputs; rejection
preserves the prior version. Same original retain/revise/retract semantics,
negative-fact inheritance and maxfour live notes. No hidden extra editor budget.

Engineering constants above are common to all six runs and not fitted to their
new outcomes. Unit tests exercise cold semantics, wrong-focus credit, executed-
point calibration, bounded review, local adverse facts and GP immutability.
Numerical preflight tests synthetic0/1/2/4 prefixes with exact frozen GP and
acquisition equality. Use three single-thread CPU workers, warm identical kernel
operators and compile the official extractor once per worker before query loops.
No operator compilation in loops. Cache exact own prefixes in a new namespace.

Seal source/protocol/old-result hashes before any new response. Commit raw LLM
receipt, both selections, all forecasts, guards, GP arrays and prestate BEFORE
the selected oracle read. Preserve every schema rejection; at most three schema-
only attempts, with an already valid proposed point locked. No performance reroll
or mid-run parameter change. Replay every query and feedback state afterward.

Primary SearchAUC is mean of all20 post-query cumulative maxima, including zero
and nonimprovement outcomes. Also final best and first query reaching that best.
Show all six paired results versus frozen V13/RBO/BO, including regressions. Do
