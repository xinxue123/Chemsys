V12 事前注册：当前incumbent预测校准与语义证据记忆

范围：只重跑 Reizman Suzuki Case2、Case4、HPLC 的新方案。
主方案memory共3条；类别对照category单独消融，仅Case2、Case4共2条。
HPLC全连续变量，类别消融不适用，不复制主轨迹冒充独立运行。
共5条轨迹，每条相同候选池、GP配方、seed=0、4初始化+16查询。
纯BO、Reasoning BO和V11仅读取封存结果。没有额外实验、隐式候选真值查询或其它任务重跑。
输入、原生GP代码、提示、实现、协议、对照SHA在正式调用前冻结；不得根据本轮结果改门限。
模型沿用授权配置openai-key.txt，gpt-6.1-terra，medium。密钥不进入产物或Git。

一、主方案
1. 使用原GP及原qLogEI，全池输入评估产生前5个未测点；完全同分用已有物理特征映射的seed0随机优先级。
2. 显示顺序仍由物理条件排序后独立洗牌，不给LLM数值GP预测或候选编号排序含义。
3. 官方Reasoning BO提示与原始稳定confidence提取函数n=1直接决定点；原函数每进程编译一次。
4. 不改GP均值、方差、核、采集值，不用KF混合候选分数，不加scope或qLogEI硬门限。
5. 每轮1次选择调用；至多4次事件知识编辑，编辑间隔至少3轮，11轮前最多3次。

二、引用语义
只给选择器提供与本轮菜单有scope交集的精简Notes和最多6条关联的历史负证据事实。
不再将所有live notes经forecast_notes重新塞入提示；完整自身已测历史和官方Insight历史仍保留。
引用分support/counterevidence/exploratory_transfer。support要求当前点范围内、active、权重大于0，
且同版本至少两次“超过当轮incumbent并有正Brier增益”的反馈；这只是观测成熟度，不是因果知识认证。
新假设、暂停或范围外知识可以启发探索，不能表述为已验证支持。不要求任何候选必须有知识支持。
未知、错版本或重复引用标unsupported；不成熟或范围外正向引用标exploratory_transfer；原响应完整保留。
引用和预测侧表问题只记警告/跳过该预测，不拒绝合法官方Insight，也不额外重问LLM改变选择。
官方Insight结构或越界点才允许至多3次有记录的格式修复；不提供实验结果用于修复。

三、事前预测和KF
只对最终选中点所适用的非撤回知识预测；暂停知识可影子评估。
预测p_LLM=P(本次实测目标>当前incumbent)。参照ID、值、历史SHA、GP SHA和概率在oracle读取前提交。
知识版本出生时的参照只保留作历史解释，不再用作后续KF预测阈值。
p_GP来自原GP预测观测分布的正态CDF，使用mu_y和sd_predictive_y。
s=1[y>当轮已知最大y]，z=(s-p_GP)^2-(s-p_LLM)^2。
沿用V9的KF过程噪声0.0025、R=max(0.0025,4(p_LLM-p_GP)^2 p_GP(1-p_GP))及原自动降权/暂停/恢复/撤回。
KF权重是预测校准的建议性记忆；准确预测失败可以校准升权，但不增加正向改善证据数。
选点前另声明improve或learn，以及不确定性、改善/未改善后如何调整；学习的价值不由单步产率直接判死。

四、事件与跨版本证据
允许事件：最近3轮停滞、最近2轮强负Brier(<-0.05)、自动暂停/撤回、最近2轮出现新incumbent、
类别连续3轮集中且当前原菜单同类并存在测量<=1次的替代类别、连续2轮不合规正向引用、活跃重叠反向规则。
初始必调用。预算和间隔优先；留出的后期调用仍需上述实际事件，不因时钟到点强制改写。
不覆盖当前菜单只标dormant，不据此撤回。不要求新scope覆盖当前5点，只需覆盖至少2个真实候选输入。
LLM撤回必须引用已完成的本知识谱系负Brier或高概率失败事实。可retain或actions=[]放弃无益改写。
跨focus、版本或ID：保留命中相同实测条件的负证据；同ID谱系还保留其原事实。记录来源版本、轮次和参照。
旧Brier不作为不同预测目标的新KF测量重放。新版本KF从初态开始，保持tentative，提示同时携带相关负事实。

五、类别对照单独消融
主方案完全不改前5菜单。category仅在查询1–8内，最多两次插入（不要求选中才计数）。
触发：连续3个查询同一类别、原前5全为该类，且至少一个替代水平在自身含初始化历史中测量<=1次。
从满足任一类别轴条件的全部未测替代点中，取原qLogEI最高者，精确同分仍用原物理特征随机优先级。
替换原菜单第5位；保留原GP第1位和其它3点，重新执行相同中性显示顺序。仍由官方选择器选1/5。
不指定任务名称、催化剂名称、候选ID或已知好点。HPLC无此通路。统计插入和真正选择的次数。
这是候选接口的扩展，必须单列结果，不是官方原生算法；不将两臂最好结果拼成主方案。

六、验收与证据边界
优先目标：memory的Case2 SearchAUC严格高于V11；Case4、HPLC SearchAUC及最终最佳均不低于V11。
同时完整报告每条轨迹对纯BO和Reasoning BO的差额，所有失败保留。类别消融独立报告，不替主方案补成功。
SearchAUC=16次查询后各次累计最佳目标的平均；首达轮次另报query和总实验序号（相差4）。
同一seed0上的定向开发检验，不是独立种子确认；日志引用与KF动作不能单独证明模块因果增益。
三任务CPU进程并行；每任务先主方案后类别消融，复用原生GP缓存和完全相同提示响应缓存。
同算子预热一次，循环重复编译计数须0。实验预算相同，但LLM调用数/费用不保证与对照相同。
独立复算官方选点、CDF、Brier/KF、当前参照、菜单和时间顺序；对照文件逐项SHA核验。
