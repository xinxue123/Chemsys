## 对模块增量的判断与轨迹证据

在本轮固定配置下，没有得到“三个模块逐项带来稳定增量”的证据。KF在Case 2–4主评估的均值仅+0.021pp，包含Case 1后转为负值；B4的主评估AUC下降；刷新能在部分条件下修复损失，但完整组合在四种知识条件的平均AUC均低于G0。这里的判断仅限本配置和seed0，不能据此否定所有KF、B4或事件策略。

KF系数用于校准知识相对于当前GP的增量，不是知识真实性分类器。Case 2“助手初始建议”中，16轮部署幅度均为1、全部选择与G0相同，AUC差0。Case 4“混合错误”从第2次追加查询开始分歧：幅度0.862900，G0选择p04411、产率23.420538%，G1选择p01424、产率68.522728%。这一单步产率改善仍未转为整条轨迹的AUC收益，G1−G0最终为−1.095619pp；不能把单步更高产率当作搜索效率已经改善。

B4最大的一处主评估损失是Case 4“助手初始建议”，G2−G1为−4.408957pp，而最终最佳产率反而提高0.594460pp。第2次追加查询前两组历史、GP及2341个预算候选完全相同：G1保留四条知识、幅度0.964071，选p01589得到94.173752%；G2按B4诊断移除H1（催化剂P1-L3偏好），扩展区域并启用其新校准先验、幅度1，选p01486得到85.022827%。两点都满足同一qLogEI门限，模型机会损失小不等于实际产率损失小。G1在第4次追加查询已获得95.626068%，G2直到第14次才超过95%，因此后期更高终值抵不过早期搜索延迟。这里测到的是B4区域选择及随之切换校准状态的联合条件效应，未额外声称已分离二者。

刷新收益具有条件依赖。Case 2“混合错误”在第3、8、11次追加查询前触发刷新，相对G2从第3次选择开始分歧，AUC增加3.132221pp，8个incumbent位置更高、0个更低，同样的40.085316%最佳值从第11次提前到第10次获得。Case 4同条件刷新增加2.046996pp，但只修复了此前KF及B4损失的一部分，完整组合相对G0仍下降1.148034pp。Case 2“错误类别”的刷新则使AUC下降1.951878pp，Case 3“混合错误”下降2.338213pp，说明事件触发和有效JSON输出并不保证更新后的知识更有用。

Case 4“助手初始建议”刷新于第5、10次追加查询前，G3−G2的AUC改善1.276930pp，但最终产率下降1.420052pp；相对G0仍下降3.002832pp。这是“相对受损组合有所修复、相对原基线仍不足”的例子。Case 1也完整保留：错误类别和混合错误条件的刷新分别下降5.596593、4.443620pp，解释了为什么全部四Case的刷新均值为负，Case 2–4主评估却略为正。

## 实现边界与公平性

四组使用同一MixedSingleTaskGP、4692候选、相同初始化、原GP/MC种子、MC512 qLogEI、协方差jitter1e-6、预算log(4)*(16-t)/15。催化剂只作名义标签，连续RBF不读其编号距离。四个Case、四个条件的G0完整20条观测均与之前Mixed GP仅预算门限轨迹一致，16条基线逐项核对；初始知识与confidence在四组完全一致，事件组不重生成初始知识。

四组统一使用官方LGBO区域协方差均值偏移，64个连续Sobol点×8催化剂、连续smooth0.08，confidence按原生实现转为3Φ^-1(c)。代码保留官方float32 erfinv的数值精度，没有换成另一种精度的逆正态算法。没有旧新方案的加性指示函数，也没有0.5SD限幅。

本轮KF是对该同一偏移场的全局幅度校准：状态[b,a]，初始均值[0,1]，P0=diag(.0025,.25)，Q=diag(.000025,.0025)，R=GP实验前观测方差+(3pp)²噪声地板（归一化方差0.0009）；measurement=y−mu_GP，H=[1,原区域偏移_y]，Joseph更新。部署clip(mean_a,0,1)，b只作校准干扰项，不进入采集。幅度初始1，避免把先验强度改变当作校准收益。该KF与旧四假设加性残差滤波并不等同，是保持区域注入一致所需的明确适配。

不同区域几何＋confidence各有独立校准状态。B4撤销条件后扩展区域，不直接继承完整区域的校准；新的区域从相同先验开始。返回同一几何时仅复用该区域自身的更新，并按经过轮数增加过程噪声。这一规则在三个KF组中相同，B4或刷新引起的区域切换会自然改变校准状态，不应隐藏这种中介作用。系数是工作模型的幅度，不是知识为真的概率；缺少区域时原偏移场为0，记录的缺省系数1不代表可靠知识。

B4沿用原最大基数/ID并列规则，在未引导评分预算内诊断各坐标经验；只用剩余区域做软均值注入，实际查询仍在整个预算集最大化修正qLogEI。它检验采集预算兼容性，不认证化学真伪。

事件组把已给定初始知识视为虚拟第1轮调用，最多3次后续真实刷新、最小间隔2轮、最后刷新第14轮。触发沿用3轮停滞(<0.5pp)、2次连续|创新z|>2.5、B4冲突、空知识。每条轨迹独立调用config.txt中的deepseek-flash，只给自己的已观察前缀、实验前残差、当前GP摘要、知识、当前区域校准与B4诊断；不发送case、知识真伪/条件标签、其他方法轨迹或未查询产率。四个固定坐标槽只允许保留、修订、撤销、补充区间/类别集合，confidence不变；新增区域仍用同一注入公式。保留现有几何不会重置其校准。

正确/错误类别/混合错误三组仍为参考结果知情的人工压力测试。刷新模型收到的是不保证正确的初始经验，不收到真伪标签。各组均保留全部计划轨迹；失败轨迹延续最后已知incumbent，不能从分母删除。
