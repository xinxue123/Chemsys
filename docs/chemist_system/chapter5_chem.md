# 第5章 Chem：化学知识辅助实验决策的可靠利用与边界

本章基于 `chemist_system` 建立可撤销化学假设、固定完整参数域、统一高斯过程和有限候选池联合诊断机制。完成20个数学任务的3,200条测试轨迹、三个反应模拟案例的480条固定先验测试轨迹，以及当前助手参与的75条闭环测试轨迹。全部测试轨迹进入评价，提前停止不剔除。

结果支持两个有区别的结论。联合诊断能够在给定采集函数机会预算内，精确找到撤销数量最少的假设子集，并避免直接采用有害约束导致的搜索停滞；但本次固定先验实验不支持其搜索效率普遍超过单候选校验。真实助手实验的SearchAUC差异较小、最终后悔值反而略差，且没有出现联合专属冲突。因此，本章将贡献限定为可执行、可诊断、可审计的知识利用接口及其适用边界，不宣称普遍优化优势或真实合成成功。

## 5.1 研究问题与已有工作的关系

结构生成给出满足晶体学约束的候选结构，并不直接确定其可行制备条件。Chem接受目标结构身份、既定路线、参数硬域、证据包与已观测实验，在路线内部辅助选择下一组条件。本章不训练新的语言模型，不自由生成未获支持的合成路线，也不调用硬件执行实验。

化学经验通常具有条件性。例如“较高温度有利于反应”可能同时受催化剂、停留时间和副反应影响。把经验直接写成不可恢复的搜索边界，会使少量错误建议排除有效区域；把语言模型给出的置信度当作经校准的产率概率，也缺少统计依据。本章研究的问题是：在保持完整域和数值模型一致的条件下，如何允许经验影响选点，同时明确其来源、组合冲突、撤销理由及机会成本。

[LLINBO-Justify](https://arxiv.org/html/2505.14756v2#S2.SS4)已经以采集函数阈值接受或拒绝LLM候选，因此“建议不得明显差于当前采集函数最优点”不是本章的新理论。[FGSS-BO](https://arxiv.org/html/2610.21246v1)也已提出有身份和证据记录的假设管理，并报告选点改变的机会成本。本章讨论的增量是有限池上多条可执行假设的联合相容性，以及预算条件下按撤销数量求解的精确诊断。该问题属于小规模最大满足／最小修订问题，不将枚举算法本身包装为新的通用优化理论。

## 5.2 任务、证据和假设表示

任务记为

\[
\mathcal T=(p,r,\mathcal X_0,\phi,g,\mathcal K),
\]

其中，\(p\)为目标晶相身份，\(r\)为既定路线，\(\mathcal X_0\)为满足硬约束的冻结候选池，\(\phi\)为完整参数编码，\(g\)为预定义目标变换，\(\mathcal K\)为允许使用的证据。运行状态、审查状态、推荐状态分别记录；程序运行成功不自动表示化学审查通过。

数值输入按不可变硬边界缩放至[0,1]，类别变量使用包含全部类别的固定独热编码。历史缺失参数不以中点补齐。LLM不得删除输入维度、改变硬边界、修改目标值或给出可执行Python预测函数。未知或定量失败的结果保留为null，不作为真实零产率输入GPR。

每个假设版本最多包含四条原子谓词，支持原单位区间、类别允许集合和归一化数值坐标上的线性不等式。每条假设包含固定身份、版本、证据编号、已观测编号与适用性说明。相同谓词重复提交会被拒绝；来源编号校验只证明引用存在，不证明假设在化学上正确。

`HypothesisManager`保存更新事件与原始回答。新增查询数为0、4、8、12时各预留一次建议机会；每条方法轨迹最多四次。非法回答与解析失败消耗该次额度，并保留上一有效版本。后续有效更新可以撤回或修改经验假设。确定性控制器的“本轮撤销”不等同于永久判定化学知识错误，下一轮仍对当时的活动版本重新诊断。

## 5.3 联合诊断与有界最小修订

在第\(t\)轮，令\(U_t\)为未查询的硬可行候选，统一GPR给出

\[
a_t(x)=\mu_t(x)+2\sigma_t(x),\quad
a_t^*=\max_{x\in U_t}a_t(x),\quad
E_t=\{x\in U_t:a_t^*-a_t(x)\le b_t\}.
\]

新增查询轮次\(t=1,\ldots,16\)采用冻结预算

\[
b_t=0.05(16-t)/15.
\]

活动假设集合为\(H_t\)，子集\(S\)约束下的候选为

\[
C_t(S)=\{x\in U_t:\forall h\in S,\ h(x)=1\}.
\]

B4首先求解

\[
S_t^*\in\operatorname*{argmax}_{S\subseteq H_t}|S|,
\qquad C_t(S)\cap E_t\ne\varnothing,
\]

再在所选子集的预算内候选中最大化UCB。等大子集按排序后的假设编号字典序选择；UCB并列按候选编号选择。撤销集合为\(H_t\setminus S_t^*\)。比较使用实际浮点减法，不通过隐藏容差扩大承诺的预算。

当\(U_t\ne\varnothing\)时，全域UCB最大点属于\(E_t\)，空假设子集始终可行。因此枚举全部\(2^m\)个子集必能找到解；最大化保留数量等价于最小化撤销数量。所有保留较多但不可行的子集均有穷举记录，由此可以独立核验最少撤销结论。\(m\le4\)时最多检查16个子集，已构建谓词矩阵下复杂度为\(O(2^m mN)\)。

诊断区分空交集与质量排除：前者表示完整约束没有剩余候选，后者表示仍有候选但全部落在预算外。联合专属冲突进一步要求每条假设单独与\(E_t\)相容，但它们的合取与\(E_t\)不相容。控制器同时保存按集合包含关系最小的冲突子集，以说明哪些组合导致排除。

该保证仅涉及当前模型、当前历史和当前有限池。它不保证真实单步收益为正，不保证累计物理后悔值有界，也不证明假设的化学真伪。固定的\(\kappa=2\)与拟合所得方差没有在本实验中得到物理覆盖率校准；不同方法在选点后产生不同历史，不能把当前轮的UCB差界直接解释为整条轨迹相对B0的性能界。

## 5.4 共享实现与对照

共享基础修正包括：首次进入GPR时不重复添加当前观测；输入维度与边界固定；完整候选一次批量预测；随机状态、五次优化器重启和确定性噪声\(10^{-6}\)显式指定；观测误差按目标单位平方加入方差。关键审查失败覆盖通过标记，定量失败和相鉴定置信度不再冒充数值产率。

研究控制器每轮仅以独特已观测记录拟合相同的 `ConstantKernel × Matern(ν=2.5)` GPR，`normalize_y=False`。相同任务、种子、观测前缀和软件版本复用预测缓存，缓存键不包含未来目标值。硬域和已查询掩码优先于所有软假设。

| 方法 | 可执行决策规则 |
| --- | --- |
| B0 | 全部未查询硬可行候选中最大化UCB |
| B1 | 完整假设合取内最大化UCB；交集空则停止 |
| B2 | 第4、8、12、16次新增查询均匀探索全域，其余按B1；非逃逸轮交集空则停止 |
| B3 | 每轮检验一个外部候选，预算内接受，否则退回全域UCB最大点；不搜索假设子集 |
| B4 | 联合诊断后按最大保留数量、固定并列规则选点 |
| A1 | 仅删除逐条不相容假设，再使用剩余合取；可能遗漏联合冲突 |
| A2 | 完整合取与预算相容则使用，否则全部撤销 |
| A3 | 只要求交集非空地最大化保留数量，忽略机会预算 |

B3是参考LLINBO-Justify思想建立的匹配机制对照，不是原论文完整系统的复现。固定先验轨道的候选优先序先按满足假设数量、再按编号冻结；真实助手轨道使用同次建议返回的至多四个候选队列，逐轮消耗。所有方法使用相同初始点、目标变换和数值模型，不能据本实验宣称击败未直接运行的文献系统。

## 5.5 冻结实验与评价

每个任务512个候选，四次初始化加16次新增查询，测试种子0—4配对。数学层采用五个家族各四个实例，维数为2—5；分别为各向异性单峰、耦合脊、双峰、周期多峰和非线性交互。函数、中心、Sobol种子和四类先验的完整定义保存在[实验前方案](chapter5_research_design.md#552-第一层-数学优化与机制正确性)、冻结输入及生成代码中。开发使用独立的\(r=4\)实例。

四类固定先验为相关先验、单条有害、联合才有害和混合有害。其构造**使用完整oracle设计压力条件**：相关约束保留池内最高10%的52个点；联合有害约束逐条保留高值点而组合排除它们。该设计用于比较已知冲突模式，不代表自然LLM产生错误先验的分布；完整oracle不进入运行时GPR或LLM上下文。

反应层采用[Summit 0.8.9官方Reizman–Suzuki预训练模型](https://gosummit.readthedocs.io/en/latest/_modules/summit/benchmarks/experimental_emulator.html)。Case 1开发、Case 2—4测试；每个池包含八类催化剂各64个Sobol连续点。停留时间60—600 s，温度30—110 ℃，催化剂负载0.5—2.5 mol%，目标为预测产率除以100。该范围与类别表是给定任务的硬域，不是面向实际实验室的新操作建议。

模型资产和缩放器均记录哈希。加载时将对象初始化训练轮数设为零，并禁止优化器更新与反向传播；加载后逐张量核对保存权重与缩放器。四个案例的独立前向和官方公开接口核对均低于预先固定的\(10^{-4}\)个百分点容差，独立前向最大误差为\(1.526\times10^{-5}\)个百分点。每个案例一次批量生成512点隐藏缓存，后续BO不重新训练或查询模拟器。

真实助手使用用户指定的当前Codex助手，记录配置别名`gpt-6.1-sol`和推理设置`max`；提示词、上下文、回答和版本事件均存档。定性证据包依据[原始Suzuki研究摘要](https://pubmed.ncbi.nlm.nih.gov/27928513/)及官方域定义，不提供反应响应表或池最优值。紧凑展示包含已观测历史和每类两个公开候选选项，完整请求仍保存512点参数。相同请求哈希共享回答，但各轨迹仍消耗其逻辑建议额度。

必须限定这种实验形式：各回答来自同一聊天，模型并未处于相互隔离的会话；服务端不可变权重快照、独立采样参数与逐事件token用量不可核验。逻辑建议事件不等于独立API调用，精确相同上下文的回答复用也不是独立重复采样。它是实际助手参与的闭环演示，不能作为完全隔离、固定权重的模型复现实验或对化学知识因果增益的强证据。

| 轨道 | 开发轨迹 | 测试轨迹 | 测试完成 | 测试提前停止 |
| --- | ---: | ---: | ---: | ---: |
| 数学固定先验 | 160 | 3,200 | 2,727 | 473 |
| 反应固定先验 | 160 | 480 | 422 | 58 |
| 实际助手闭环 | 5 | 75 | 75 | 0 |

评价采用\(\mathrm{Best@}q=\max_{i\le q}f(x_i)\)、\(\mathrm{Regret@}q=f^*_{pool}-\mathrm{Best@}q\)，以及

\[
\mathrm{SearchAUC}=\frac1{16}\sum_{t=1}^{16}\mathrm{Best@}(4+t).
\]

停止后沿用已有最优值至预算结束，全部531条测试停止轨迹保留在分母中。目标不按测试池极值重新缩放。数学比较先在任务内配对种子，再按五个函数家族聚类；文中95%区间为10,000次家族重抽样的探索性百分位区间。反应测试只有三个独立案例，不把15个种子视为15个化学体系，不给出小样本强显著性结论。

## 5.6 实验结果

### 5.6.1 机制、来源和完整轨迹核验

独立评价器不调用选点函数、谓词编译函数或原始评分函数，而是从原始文件重建完整域、已观测前缀、谓词矩阵、全部方法决策与固定预算指标。测试层共核验53,821次新增决策、68,841条oracle查询；另对26个任务分别直接调用sklearn重建一次GPR，预测数组最大绝对差为0。这是抽样数值重拟合核对，不能表述为重拟合了全部53,821次模型。

| 全方法硬约束违例／重复查询 | 0／0 | 0／0 | 0／0 |

实际助手测试产生240个逻辑建议事件、174份不同上下文回答，开发另计16个逻辑事件、12份回答。测试中两份回答引用了当前轨迹未观测的编号，分别发生于Case 3、seed 4、B3第2次建议，以及Case 4、seed 4、B2第2次建议。两次均被拒绝、消耗额度并保留上一有效版本，未把引用编号转化为观测。错误回答没有覆盖或补写。此结果验证了来源检查的作用，也实证体现了共享聊天上下文的局限。

数学计算曾遇到Windows原子提交文件锁，随后核对两份临时状态与已提交观测前缀，恢复相同20条观测的事务，并仅补齐未完成分组；原始错误与恢复回执均保留。没有因基础设施错误改动参数、重置查询历史或删去差轨迹。

### 5.6.3 消融、正确先验保持与恢复

四先验汇总下，数学B4相对A1、A3的AUC差分别为+0.02395、+0.05407，反应为+0.03552、+0.07019，说明逐条检查或仅保证非空可能不足。相对全部撤销的A2，AUC差则为数学−0.00656、反应−0.00546；最少撤销的优化优势仍未建立。不同方法产生不同历史，因此联合冲突计数不可直接当作同状态上的因果消融比较。

相关先验下，数学B4−B0的Regret20均值为−0.02656，探索性家族区间[−0.05376,+0.00088]；反应三个案例的差分别为−0.01663、0、−0.00036。观测到的平均变化满足预设0.02保持界的方向，但数学F1、F5仍有局部下降。五个家族的探索性区间与三个案例不足以证明一般化学任务上的正式非劣性。

按预设\(\delta_{rec}=0.02\)，有害先验轨迹中B4最终后悔值不超过配对B0加0.02的比例，数学单条有害为83/100、联合有害83/100、混合80/100，合计246/300。反应三类分别15/15，合计45/45。数学54/300未恢复至此界内，说明零UCB预算违例不能替代真实优化恢复成功。

SearchAUC略升，但三个案例的最终后悔值均比B3更高。B4只改变40/240次查询，且联合专属冲突为0/240；实际助手结果不能验证联合诊断相对逐条检查的必要性。共有聊天历史、缺少不可变后端快照及独立token记账进一步限制其可推广性。

### 5.6.5 效率与资源

本地主机实测20个逻辑CPU、31.84 GiB内存、RTX 4060 Ti约8 GiB显存。正式BO采用四个独立CPU进程，每进程一个BLAS线程，复用特征、同版本谓词矩阵和相同观测前缀的预测。模拟器在单CPU线程预热后一次生成候选缓存，各案例512点推断约0.04—0.05 s，无须GPU训练或集群。

B4测试中组合决策累计计时约为数学11.07 s／6,400次、反应1.64 s／960次、助手0.26 s／240次，即每次约1—2 ms。该计时包含当前进程中的Python与NumPy开销，不能外推为任意候选规模的硬件速度。所有轨迹均记录`operator_compiles_in_loop=0`；矩阵“编译”指向量化构建，没有循环内JIT。真实助手等待、共享聊天推理与独立token成本未能从界面准确分摊，不报告虚构的费用或整项墙钟加速比。

## 5.7 Ce–Al–Ge接口示范与未通过的材料证据

主表16条原记录中，两条定量失败、两条DSC处理状态不同，剩余12条只达到暂定数值筛选条件。两个失败编号为`CeAlGe_20-90-10.xy`与`CeAlGe_10-35-25.xy`；它们原有零标签不作为真实零产率使用。另两个数据版本分别有14、15条，共同记录的标签一致，不能计作独立重复实验。

代码把文件名配比解释为名义投料质量，并按原子量换算三元原子分数，但缺少原始实验记录验证此语义。逐样本热历史、共同处理条件与测量协议也没有完整来源。目标相身份还有明确的本地不一致：旧暂定方案写I4/mmm，而本地`CeAl2Ge2.json`标注P-3m1、来源`user`、无source_id。可能存在不同结构假设或记录错误，当前证据不能确定应把哪一项当作实验晶相真值。

因此材料适配器返回`execution_status=OK`、`review_status=HOLD`、`recommendation_status=needs_validation`，保存12个暂定候选的完整Ce/Al/Ge组成和全部16条审查记录，但输出空推荐列表，实际oracle查询与LLM建议数均为0。不运行或报告2+6材料效能曲线。详见[可追踪接口回执](../research/chapter5/material_interface_demo.json)。

这一处理也限定了前文结构生成与Chem的连接：目标结构、晶相身份或路线证据未通过时，生成模块的几何／数值可行性不能直接转化为材料制备已获支持的结论。

## 5.8 讨论与本章结论

本章建立了从经验文字到可撤销谓词、联合冲突回执和实际选点的检查链，并通过完整轨迹与独立枚举验证其有限池性质。可靠利用化学知识要求同时满足来源可追踪、硬约束优先、未知结果不伪造、软约束可撤回，以及优化效果由完整分母上的结果验证。

本次结果支持相对盲目使用有害约束的改进，也揭示两项尚未解决的问题。第一，最大保留数量会受假设粒度和编号并列规则影响；即使拒绝字面重复谓词，也没有解决逻辑等价但表示不同的经验如何公平计数。第二，UCB的局部相容性与真实优化效率并不一致。本次B4在固定先验SearchAUC上落后于B3和A2，在实际助手实验中也没有终点优势。

因此，本章不把“程序通过”当作“研究收益成立”。现阶段可确认的成果是实现、可核验机制、完整负结果和材料证据边界。若后续研究要提出更强的化学决策效能主张，需要新的预注册测试、隔离且版本可核验的LLM调用，以及经核实的路线、晶相和实验记录；不能在本测试集上调预算、换种子或只展示有利案例后重新宣称验证成功。

本章代码、冻结输入、原始轨迹、GPR快照、来源错误、停止与恢复记录均可追溯；复现入口和证据文件索引见[实施说明](chapter5_implementation.md)。
