LLM first point, progressive handoff to exact pure BO

The user clarified that only the initial point is fully LLM selected. Transfer
starts with the second choice. Do not replace this with four fully LLM-controlled
choices, or an immediate jump to seven pure-BO choices. GP fitting and decision
authority are distinct. The existing GP recipe is not changed by this controller.

This module implements and qualifies a controller only. It has not produced a new
optimization benchmark. Old trajectories, LLM replies and GP sources remain frozen.

For an eight-query example, define the LLM authority ceiling a_t=(8-t)/7. The
ceiling contracts from1 on query1 to0 on query8, independently of Note versions
or refresh timestamps. Initial conditions remain unrestricted by observed yield.
The first point must be an executable LLM proposal with the original physical
projection rules. Subsequent choices use the full current native qLogEI array.

Eligible knowledge is active/provisional with KF reliability>=.2. A favour claim
also needs its pre-observation improvement probability>=.5. This distinguishes
credible failure forecasts from positive recommendation value. Avoid claims can
provide negative regional preferences. No LLM value is inserted into GP mean,
variance, observations or qLogEI.

Let r_t=min(1,max(eligible reliability)/.4), zero for no eligible claims. A draft
budget is epsilon_t=log(4)*a_t*r_t. Retain candidates whose qLogEI is at least its
full-pool maximum minus epsilon_t. Within that budget use the sum of permitted
regional favour reliabilities minus avoid reliabilities as a cached knowledge
preference. Select the native qLogEI maximum within the best preference level;
with no discrimination fall back to the native full-pool maximum. A new refresh
proposal is admissible only inside the current budget and preference, with
permitted favour support. The time ceiling never resets on refresh. Actual
knowledge confidence may change within that ceiling after real feedback.

On the final query, ignore knowledge for selection and use the original pure-BO argmax
and tie rule. epsilon=0 alone is insufficient to guarantee the same native point
when multiple qLogEI maxima exist, so the endpoint explicitly preserves its tie
priorities. No usable knowledge also returns control to pure BO early.

The log(4) allowance and linear ceiling are transparent draft parameters, not
performance-validated settings. Mechanism checks use synthetic counterexamples
and one already-observed Case 1 prefix. They verify early knowledge influence,
confidence reduction, gradual contraction, paused-rule protection, no promotion
of accurate failures, refresh clock inheritance, GP-array immutability and an
exact pure-BO terminal choice. A complete synthetic feedback update also checks
that a bad prospective forecast reduces KF trust and changes the following choice.
The held-prefix shadow is not a complete trajectory
or evidence of SearchAUC improvement. No new LLM call or oracle lookup is made.
