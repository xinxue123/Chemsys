V13 from-zero mechanism ablation, registered before new decisions

All old methods, code, reports, caches and publications remain immutable.
Eight historical tasks, starting-menu seeds0,1,2,3, zero free observations,
20 paid queries per trajectory. Native task-specific GP, MC512 q=1 qLogEI,
top-five menu, feature-keyed priorities, display order and numerical seed0
remain unchanged. A starting seed changes only the query1 prior/menu.

Five V13-interface arms per task/start (160 traces):
  full: exact frozen V13; replay its archived validated responses.
  fixed: hold m,P,probability_positive,r at their native birth values. Continue
    prospective forecasts, raw Brier feedback, counters, permissions and editing.
  no_refresh: allow the original first editor call atq2, even if it returns no
    accepted Note, then disable all later editor calls. Keep native KF/permissions.
  neither: combine fixed and no_refresh, retaining the same initial Note(s).
  no_notes: disable all Note editing and keep notes empty. Retain the identical
    V13 selection system prompt, official Insight history and GP menu. Its empty
    knowledge_uses/assessments are still validated. This isolates the structured
    knowledge bundle from the V13 chooser, not from all implicit LLM knowledge.

The four Note arms share the same initial editor response, because the complete
scientific input before that intervention is identical. Their first point is
also shared through the same unchanged V13 query1 prompt. Each point still costs
one paid query in each arm; there are no free measurements or inherited trials.
Empty initial knowledge is retained, never replaced by a hand-picked hypothesis.

Use a single immutable response map within each task/start, keyed by exact
system/public JSON plus requested model/effort and request kind. Seed it with
archived V13 responses only, using full original packets and raw accepted bytes.
An old response may be used only for an identical scientific input in that same
task/start. Different public inputs get a fresh independent child agent. Identical
new inputs across arms reuse the first validated response, never the best one.
No cross-start response sharing. All reuses preserve source/response hashes and
are explicitly labeled, not counted as new independent language realizations.
This is a conditional diagnostic of a frozen response map. It does not measure
independent-response repeatability, which remains a separate question.
