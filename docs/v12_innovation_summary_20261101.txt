V12方案创新点整理：实验反馈驱动的知识可靠性管理

定位
V12研究如何把LLM给出的化学或实验过程假设，变成能够事前预测、事后检验、动态调整可信度并追溯来源的决策依据。
核心贡献可概括为：面向当前最优实验，以相对GP的预测增益校准知识可信度，通过有语义约束的证据记忆和事件驱动生命周期，使知识在固定BO候选范围内参与后续决策。
本文只梳理已冻结的V12主方案memory，不修改代码、参数、提示或实验结果，不开展新实验。
原V12协议SHA256：1a5d59471d799105003297e427a8f907801b370e59a997cdb93c142da02fb3f6；核心提交c0fc512。
截至整理时，seed0独立响应重复与seed1/2/3配对验证均已完成，冻结源文件和8456个受保护历史文件核验通过。

一、与Reasoning BO的关系
Reasoning BO原论文已有BO提供候选、LLM生成假设并按置信选择、使用历史Insights、动态Notes和知识检索等机制。
因此，“LLM+BO”“用实验历史更新知识”“BO生成五个候选再由LLM选择”属于继承的研究基础，不单独主张为V12原创。
V12直接复用官方优化提示模板和稳定confidence提取函数，统一有限候选池、固定初始化和每次选1个的4+16预算。
原论文含LLM初始化、批量选择、图/向量知识管理和模型后训练；本地配对对照并不等同于复现原论文的所有设置。
V12的可辨识扩展是将知识版本、事前概率预测、相对GP评分、KF状态、引用语义和历史反证关联为可复核的闭环。
该定位是相对于已核查Reasoning BO论文与仓库的具体方法扩展；本次未完成全领域系统查新，不使用“全球首次”等表述。
来源：[Reasoning BO原论文，方法3.2/3.3与算法1](https://arxiv.org/html/2505.12833v2)。

二、三项主要方法贡献

贡献1：面向当前incumbent的相对GP知识可靠性估计
研究问题：LLM建议听起来合理，并不意味着它提供了比已有GP更有用的预测信息。
V12为适用于已选实验条件的每个知识版本，记录“本次结果超过当前已知最优值”的概率预测，而后与GP对同一事件的预测比较。
令b_t=max{过去已测y}，s_t=1[y_t>b_t]；选中点为x_t：
  p_LLM,h,t = P_LLM(y_t>b_t | 知识h、当前自身历史、x_t)
  p_GP,t = Phi((mu_GP(x_t)-b_t)/sigma_predictive_GP(x_t))
  z_h,t = (s_t-p_GP,t)^2 - (s_t-p_LLM,h,t)^2
其中sigma_predictive是观测预测标准差，不是仅潜在函数的标准差。
z>0表示该次LLM概率比GP更接近实测事件，z<0表示更差。即使产率提高，如果GP预判更准，知识也可能被降权。
所有概率、目标参照、知识版本、观察历史和GP哈希在读取该次结果之前固定；不能在看到结果后改写预测。

每个知识版本用一个标量KF平滑这一相对预测能力信号：
  P_minus = P_previous + 0.0025
  R = max(0.0025, 4*(p_LLM-p_GP)^2*p_GP*(1-p_GP))
  K = P_minus/(P_minus+R)
  m_new = m_previous + K*(z-m_previous)
  P_new = (1-K)^2*P_minus + K^2*R
  w_raw = 0.8*Phi(m_new/sqrt(P_new))
当z<=1e-12时，w_new不允许超过旧权重；其它情况使用w_raw。知识初始m=0、P=0.25、w=0.4。
R是以GP成功概率为参照设计的测量噪声近似，w是该滤波模型下的可靠性评分，不是化学命题为真的概率。
每轮参照更新为当前incumbent，避免长期只比较知识出生时已经容易超过的旧参照。

可主张的增量：把“是否值得继续相信这条知识”转化为与当前优化事件一致、相对数据模型的可检验预测问题。
继承部分：Brier评分、KF和高斯CDF本身均为已有工具；贡献在评价对象、参照及其与实验闭环的组合方式。
边界：相对概率评分是补充预测价值的操作性指标，不等于证明化学规律正确、具有因果作用，或包含GP从未利用的信息。

贡献2：区分预测校准、正向支持和历史反证的版本化知识记忆
研究问题：正确预测一个实验会失败，也可能让概率校准评分提高；若据此认定“该方向值得促进”，会错误强化知识。
V12分别保留校准权重与正向改善证据。support需要：知识active、权重大于0、选中点在scope内，且同版本至少两次同时满足真实改善和正Brier增益。
只有准确预测失败时，可以增加校准可信度，但不会增加正向改善证据数。两次成功仅是预设的观测成熟度条件，不是统计显著性或因果认证。
引用分为support、counterevidence、exploratory_transfer；新假设、尚不成熟或范围外迁移不能被记为已经验证的正向支持。
无当前菜单覆盖只表示暂时不相关(dormant)，不能直接当成反证并撤回。

知识被修订后生成新版本，保留来源、轮次、scope、参照和实测反馈的关联。
同谱系负事实，以及实际测量点落在新scope内的负事实，可以跨版本、focus和ID保留。
新版本KF从初态开始，旧版本的数值Brier评分不重放为新版本的独立测量；相关历史事实继续作为提示中的谨慎依据。
因此，改写文字、改变关注变量或更换ID不会自动清空适用的反证。
匹配依据是显式谱系和物理条件scope，不是任意自然语言等价命题识别，不能保证识别全部语义重述。

可主张的增量：建立“事实保留、评分目标有版本、证据用途有类型”的知识管理机制，减少把校准成功误当方向成功，以及修订后遗忘反证。
实现边界：校验会记录/规范引用用途，但不因侧表问题重新抽取LLM回答或改掉一个合法选点；它不保证LLM内部绝不误用旧经验。

贡献3：证据状态驱动的知识生命周期与事件刷新
研究问题：知识的可信度和适用性会随反馈改变，既需要停止持续失准的建议，也需要允许有新证据的假设修订或恢复。
KF逐次反馈自动控制权重和active/paused/retracted状态：
  连续两次明显负增益，或至少两次反馈后正增益概率<=0.20，触发暂停；
  连续四次明显负增益，或至少四次反馈后正增益概率<=0.05，触发撤回；
  暂停至少两个查询后，连续两次明显正增益且正增益概率>=0.60，可恢复active。
“明显增益”的绝对阈值为0.02。暂停知识可在scope命中已选点时作影子预测，不额外占实验查询。
自动撤回后的原版本不再接受新反馈；LLM可根据新证据显式修订为新版本，相关旧反证仍保留。

LLM知识编辑由实际事件触发：优化停滞、明显负预测、自动生命周期变化、新incumbent、类别集中缺乏对照、反复不成熟支持引用或重叠相反规则。
每16次查询最多4次编辑，编辑间隔至少3轮，第11轮前最多用3次，为后期保留一次机会；仍须有事件才调用。
LLM可保留、修订、撤回或新增，也可actions=[]不改写。有记录的负预测事实是LLM撤回的必要依据。
由此形成“数值证据更新状态，语言模型修订假设内容”的分工。

可主张的增量：将知识状态、何时重审、为何撤回及恢复条件绑定到同一实验反馈链，形成可检查的自适应知识管理。
边界：事件触发并不自动保证更新后知识更好；阈值属于冻结的设计选择，目前未证明理论最优。

三、知识如何影响实验选择：当前实现的准确表述
实际顺序为：
  自身已测数据拟合原GP -> 原qLogEI给出前5未测候选 -> 必要时事件编辑知识
  -> scope检索相关Notes/负事实并标明权重和状态 -> 官方Reasoning BO置信规则选1个
  -> 对选中点适用的知识给出事前概率并持久化 -> 获取该点实测结果
  -> 相对GP评分、KF与生命周期更新 -> 在后续提示中使用更新后的证据状态。

当前回合的知识概率是在确定选点之后、执行实验之前提交的审计预测，不是对全部候选做概率评分后直接排序。
KF权重通过知识提示、状态、引用资格和事件管理影响后续LLM推理，不直接进入qLogEI或数值候选分数。
GP均值、方差、核和采集函数均保持原始计算；主方案的5个候选始终都可被选择，最终选择仍由官方稳定confidence排序n=1确定。
这给出了候选范围和反馈顺序的约束，没有提供“每步不比BO差”的保证，也没有限制与BO第一名之间的数值机会损失。
已撤回/暂停记录仍可能以带状态的历史提示被检索，不能声称从LLM上下文中完全删除。
保留GP及候选后筛选属于继承的架构基础；V12的差异在于其上的证据校准与知识管理，而不是新的GP或采集函数。

四、验证与可复核性贡献
每轮保留原提示/响应、知识版本、选点前预测承诺、原GP数组、选中候选、真实反馈和KF更新，支持从日志重建决策。
候选编号不作为化学距离或排序含义；使用真实类别核/原任务GP与物理特征排序，冻结候选池、预算和对照。
分两阶段检查随机性：固定seed0、隔离缓存独立LLM重复；随后seed1/2/3下与BO统一初始化配对。
这是支持方法可信度的实验与工程贡献，不单独包装成新的优化算法。

已发生的机制动作：seed1/2/3的9条V12共81次预测反馈、38次权重下降、6次自动暂停、3次自动撤回、1次自动恢复和36次知识编辑。
其中Case 2 seed3出现自动撤回；Case 4 seed2出现自动恢复；HPLC seed1出现两次自动撤回。
本轮记录到5次符合成熟度条件的support引用，以及16次负事实向新版本附带记录；后者不是16个独立反证。
这些证明对应执行路径已经运行，不能单独证明它们造成了SearchAUC提高。

目前性能证据：
  当前验证是固定候选池的离线基准实验，反馈来自封存的模拟产率或数据集目标值，尚未新增真实湿实验。
  seed0三次独立LLM重复：Case 2的AUC为0胜3负，Case 4和HPLC各3胜0负；三任务分别报告，不与新seed混合。
  seed1/2/3配对：Case 2的AUC为3胜0负，Case 4为3胜0负，HPLC为1胜2负；合计7胜2负。
  新seed最终最佳为3胜、5平、1负。各任务AUC均值相对BO为+22.83%、+1.89%、+1.94%，HPLC均值受到seed1大幅收益影响。
这支持在部分任务和多数已测配对中改善搜索效率；Case 2的胜负反转和HPLC的退化仍需如实保留。
每新seed只有一条LLM轨迹，seed1/2在早期开发中用过；不声称跨初始化统计稳定或独立盲测成功。

尚未成立的强结论：
  未用V12版本的完整模块因果消融证明KF、证据继承、引用规范化和刷新分别带来多少性能增量。
  支持性引用成熟度、知识预测得分和化学因果正确性不是同一件事。
  只在被策略选中的点上评价适用知识，存在选择偏差；同一结果可以给多条适用知识反馈，不是独立随机化归因。
  对BO的胜出不能推出对完整官方Reasoning BO体系普遍胜出。
  旧版本B4硬筛选、GP均值修正、区域注入和主动交互检验不是当前V12主方案贡献，不能混入描述。
  类别候选替换为单独category消融，主方案未启用；已完成的seed0类别消融没有改变最终选点轨迹，不能据此声称增量收益。

五、可用于论文的贡献表述
“本文提出一种实验反馈驱动的知识可靠性管理方法，将大语言模型生成的化学假设表示为带适用范围和版本信息的可检验知识。
通过对超过当前最优实验结果这一事件进行事前概率预测，比较语言模型与高斯过程的Brier评分，并利用卡尔曼滤波递推估计知识的相对预测能力。
进一步区分预测校准、正向改善证据和历史反证，设计跨版本事实保留、知识暂停与撤回、以及事件驱动修订机制。
在保持高斯过程和采集函数不变的条件下，更新后的知识作为带可靠性标注的证据参与候选选择，形成可追溯的实验决策闭环。”
